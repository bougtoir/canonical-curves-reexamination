# Modern Re-examination of 52 Canonical Curves

**定説曲線の現代的再検証 — 外れ値依存性・サンプルサイズ・非線形関係の脆弱性**

Onishi T. 2026.

## Overview

This project systematically re-examines canonical curvilinear relationships across 8 academic disciplines using modern model selection methods (F-test, AIC/BIC, LOOCV, Cook's distance sensitivity analysis). Of the original 52 curves, **50 are analyzed**: #35 Yerkes-Dodson and #37 Weber-Fechner are excluded because their former implementations used synthetic / hand-typed arrays with no traceable primary source.

## Key Findings

| Verdict | Count | % |
|---------|-------|---|
| Not Significant | 27 | 54% |
| Robust Nonlinear | 16 | 32% |
| Outlier-Dependent | 4 | 8% |
| Insufficient Data | 2 | 4% |
| Overfitting | 1 | 2% |

**~68% of textbook nonlinear relationships fail at least one modern robustness test** (everything except the 16 Robust Nonlinear verdicts). Counts are regenerated by `run_all_analyses.py`; see `results/summary_table.csv`.

## Disciplines Covered

- **A. Economics (12)**: Phillips, Laffer, Kuznets, EKC, Beveridge, Okun, Engel, J-Curve, Rahn, Gravity, Great Gatsby, Balassa-Samuelson
- **B. Public Health (10)**: Preston, Easterlin, McKeown, LNT, Fries, Barker, Omran, Wilkinson, BMI-Mortality, Alcohol-Mortality
- **C. Demography (6)**: Demographic Transition, Bongaarts-Feeney, Lee-Carter, Coale-Trussell, Replacement Migration, Second Demographic Transition
- **D. Environmental Science (6)**: Species-Area, Hubbert Peak Oil, Keeling, HANPP, Jevons Paradox, Forest Transition
- **E. Psychology (3)**: Ebbinghaus, Dunning-Kruger, Happiness U-Curve (Yerkes-Dodson #35 and Weber-Fechner #37 excluded — see provenance section)
- **F. Physics (4)**: Hubble's Law, Kleiber's Law, Gutenberg-Richter, Moore's Law
- **G. Political Science (5)**: Lipset, Duverger, Zipf, Crime-Temperature, Putnam
- **H. Agriculture (4)**: Mitscherlich, Borlaug, Micronutrient U-shape, Body Weight Set-Point

## Methods

1. **Nested F-test**: Linear (restricted) vs quadratic (unrestricted)
2. **AIC/BIC**: Model selection across linear, quadratic, and log models
3. **LOOCV RMSE**: Out-of-sample predictive accuracy
4. **Cook's Distance**: Top 3 influential points removed; F-test repeated

## Reproduction

```bash
cd scripts
python fetch_real_data.py          # Fetch WDI/FRED real data -> data/*.csv
python fetch_additional_real.py    # Fetch NOAA, USGS, PWT, Karl Rupp -> data/*.csv
python run_all_analyses.py         # Run all 52 analyses (substitutes real data)
python generate_figures.py         # Generate figures
python generate_manuscript.py      # Generate English manuscript
python generate_manuscript_ja.py   # Generate Japanese manuscript
python generate_pptx.py            # Generate editable figures
```

The two `fetch_*` scripts download primary data from public sources and write
CSVs to `data/`. `run_all_analyses.py` then substitutes those real datasets for
the corresponding curves before computing all statistics.

Some fetchers in `fetch_additional_real.py` require a free API key exported as
an environment variable: `EIA_API_KEY` (#30 Hubbert, #33 Jevons) and
`CENSUS_API_KEY` (#46 Zipf). #5 Beveridge uses the BLS API and works without a
key (falling back to the keyless BLS v1 endpoint; set `BLS_API_KEY` to use v2).
#25 Lee-Carter requires HMD USA period death rates (`Mx_1x1`), which the
Human Mortality Database prohibits redistributing: download it with a free
account at mortality.org and place it at `data/hmd/USA.Mx_1x1.txt` (or point
`HMD_MX_FILE` at it). Only the derived `kappa_t` index is stored in the repo.
A fetcher whose input is missing (e.g. an unset API key or the HMD file above)
is skipped, and that curve is simply not re-computed for that run — no results
are published from unverified placeholder values.

## Data provenance

curves are real-data backed; #35 Yerkes-Dodson and #37 Weber-Fechner
excluded):

The 49 top-level analysis-input CSV snapshots are inventoried in
`data/source_manifest.csv`, including persistent paths, sizes, SHA-256 hashes,
source URLs, timestamp precision, acquisition conditions, and usage-term
notes. Exact historical request times were not retained; the manifest labels
the first repository commit containing each file as a UTC proxy rather than
inventing request-time precision.

  formulas and a conceptual schema — no data table). Neither had a traceable
  primary dataset, so both are dropped rather than presented as empirical.
  The analysis therefore covers **50** curves (originally 52).

Each curve's claimed source is recorded in `data/source_metadata.json`.

## Reproducing the audit and Policy Sciences package

Use Python 3.10 or newer. From `canonical_curves_reexamination/scripts`, run
`python run_all_analyses.py` to regenerate the 50-curve audit results using
the cached public-data files in `data/`. From
`canonical_curves_reexamination/quasi_experiments`, install
`requirements.txt` and run `make all && make manuscript` to regenerate the
Kansas and Fukushima analyses, manuscript figures, tables, DOCX/PPTX outputs,
and Policy Sciences validation report; run `make package` to create
`submission_policy_sciences.zip`. Raw
public downloads and source snapshots are kept under relevant `data/raw/`
directories and the top-level `data/` inputs, while `results/`, `figures/`,
`quasi_experiments/*/results/`, `quasi_experiments/*/figures/`,
`quasi_experiments/manuscript/`, and the root submission files are derived
outputs.
