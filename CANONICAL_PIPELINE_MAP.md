# Canonical pipeline map (JCPA)

Single-source chain: public data → acquisition/preprocessing → analysis →
canonical result files → tables/figures → `numbers.json` → manuscript text.
All manuscript numbers are injected from `numbers.json` (regenerated by
`build_manuscript.py`); `check_manuscript.py` re-derives headline values
independently from the canonical files and fails on divergence.

## A. Cross-domain mapping (background motivation)

| Step | Location |
| --- | --- |
| Public data sources | World Bank API, ILO/ILOSTAT, Gapminder-digitized published tables, USGS, NOAA, official statistics; per-curve provenance in `data/source_manifest.csv`, `data/source_metadata.csv`, `data/digitized_sources.md` |
| Local inputs | `data/<curve>_real.csv` (50 datasets), `data/world_bank_data.csv`, `data/us_macro_timeseries.csv` |
| Acquisition | `scripts/fetch_real_data.py`, `scripts/fetch_additional_real.py`, `scripts/data_real_wb.py`, `scripts/data_<domain>.py` |
| Analysis | `scripts/run_all_analyses.py` → `scripts/core_analysis.py` (common diagnostic: nested F-test vs. linear baseline, Cook's-distance influence removal, leave-one-out RMSE, BIC preference); `scripts/verdict_sensitivity.py` (alpha × k grid) |
| Canonical results | `results/summary_table.csv` (50 rows), `results/full_results.json`, `results/verdict_sensitivity.csv`, `results/verdict_sensitivity_summary.csv`, `results/policy_linkage.csv` |
| Consumers | `manuscript/build_manuscript.py` → Table 1 (`tab_audit`), Figure 2 (`fig_decision_tree`), Figure 3 (`fig_sensitivity`); `numbers.json` keys `n_inventory, n_curves, n_not_robust, share_*, laffer_*, lnt_*, alpha_grid, k_grid` |
| Manuscript location | "Background: cross-domain mapping"; Appendix Table A-entries via `tab_audit` |

## D. Document assembly

- `manuscript/text_jcpa.py` — title/abstract/keywords/body/captions/references; `{placeholder}` tokens only, no numeric literals.
- `manuscript/build_manuscript.py` — `table_data()` builds all tables from canonical files; `plot_figures()` draws all figures; writes `numbers.json`, `manuscript_jcpa.docx`, `manuscript_jcpa_figures_separate.docx`, `appendix_jcpa.docx`, `title_page_jcpa.docx`, `tables_jcpa.docx`, `figures_jcpa.pptx`, `cover_letter_jcpa.docx`, `submission_statements_jcpa.docx`.
- `manuscript/check_manuscript.py` — JCPA config (≤8,000 words, 150–250-word abstract, 5–6 keywords); figure/table mention-order, OMML equation, appendix citations; re-derives headline values from canonical CSVs; verifies raw manifests and Crossref/URL liveness.
- `manuscript/build_finish_pass.py` — renames to `JCPA_*.docx/pptx`, writes `FINAL_HANDOFF.md`, assembles `JCPA_submission.zip`.
- `common/build_raw_manifests.py` — SHA-256 ledgers of raw inputs.
- `common/build_review_archive.py` — `review_archive_policy_sciences.zip` (double-anonymous review tree).

## Entry points

- Full rebuild: `make final_package_jcpa` (== `make final_package JOURNAL=jcpa`; acquisition steps are idempotent skips when snapshot data exist).
- Manuscript-only: `make manuscript JOURNAL=jcpa`.
