REPRODUCTION
------------
From the repository checkout (bougtoir/wip, canonical_curves_reexamination):

    cd quasi_experiments
    python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
    make final_package_jcpa        # builds manuscript + checks + zip

Numbers are injected from numbers.json, which is regenerated by
build_manuscript.py from current analysis outputs; no manuscript number is
hand-edited.
